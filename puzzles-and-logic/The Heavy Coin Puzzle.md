ඔයා ගාව එක වගේ පේන coins 8ක් තියෙනවා. හැබැයි මේකෙන් එකක් අනිත් ඒවට වඩා බරයි . ඔයාට මේ බර coin එක හොයාගන්න මෙන්න මේ ව​ගේ **Balance Scale** (තරාදිය​ක්) එකක් හම්බවෙනවා.

**The Challenge:** මේ scale එක **දෙපාරක් විතරක් පාවිච්චි කරලා මේ coin අටෙන් මොකද්​ද අනිත් ඒවට වඩා බර coin එක කිය​ල හොයාගන්නේ කොහොමද?

**The Solution :** බොහෝ දෙනෙක් කරන්නේ 4 බැගින් දෙපැත්තට දාලා බලන එක. ඒත් ඒකෙන් දෙපාරකින් හොයන්න බෑ. නියම විදිහ තමයි **Divide by 3** logic එක පාවිච්චි කරන එක.

1. **Step 1:** Coins 8, කණ්ඩායම් තුනකට බෙදන්න (3, 3, and 2).

2. **Step 2:** පළවෙනි පාරට coins 3 බැගින් තියෙන groups දෙක scale එකේ දෙපැත්තට දාන්න.

   - **Case A (සමාන වුණොත්):** ඒ කියන්නේ බර coin එක ඉතිරි වුණ 2 අතරේ තියෙන්නේ. දෙවැනි පාර ඒ දෙක කිරලා බැලුවම බර එක හොයාගන්න පුළුවන්.

   - **Case B (එක පැත්තක් බර වුණොත්):** බර පැත්තේ තියෙන coins 3න් එකක් තමයි බර coin එක. ඒ 3න් කැම​ති දෙකක් අරන් scale එකේ දෙපැත්තට දැම්මම, බර එක කෙලින්ම අහුවෙනවා (ඒ කියන්නේ ඒ දෙක සමාන වුණොත් ඉතිරි වුණ එක තමයි බර නැත්නම් ඉතිම් ඒ දෙකෙම් බර එක තියෙන පැත්ත කොහොමත් තරාදියෙන් පෙන්නනවනේ).

මෙතනදී අපි පාවිච්චි කරන්නේ **Divide and Conquer** කියන algorithm concept එක. සාමාන්‍යයෙන් අපිට ප්‍රශ්නයක් විසඳන්න ගොඩක් වෙලාව යනවා නම්, අපි කරන්නේ ඒ ලොකු ප්‍රශ්නය (Big Problem) පොඩි කොටස් වලට (Sub-problems) කඩලා විසඳන එකයි.

- **The "Slow" Way (Linear Thinking):** Coins 8 එකින් එක කිරලා බැලුවොත් අපිට උපරිම වතාවක් scale එක පාවිච්චි කරන්න වෙනවා.

- **The "Pro" Way (Divide and Conquer):** අපි මුළු group එකම කොටස් 3කට බෙදලා (Dividing), වැඩකට නැති කොටස් අයින් කරනවා (Conquering).

### 💡 Connection to Binary Search

මේ logic එකම තමයි **Binary Search** වලදීත් පාවිච්චි වෙන්නේ. උදාහරණයක් විදිහට, ඔයා dictionary එකක වචනයක් හොයනකොට පළවෙනි පිටුවේ ඉඳන් එකින් එක බලන්නේ නෑනේ? ඔයා කරන්නේ dictionary එක මැදින් ඇරලා බලලා, ඔයාට ඕන වචනය තියෙන්නේ ඉස්සරහද පිටිපස්සෙද කියලා තීරණය කරලා අනෙක් භාගය සම්පූර්ණයෙන්ම අයින් කරන එක. ඒක තමයි **Efficiency** කියන්නේ.

**C++** වලින් code කරනකොට, memory එක සහ වෙලාව ඉතුරු කරගන්න මේ වගේ smart logic පාවිච්චි කරන එක **NOI** වැනි තරග වලදී ගොඩක් වැදගත් වෙනවා.

**The Scenario:** ඔයා රූපවාහිනී තරඟයකට සහභාගී වෙනවා. ඔයා ඉදිරියේ වසා ඇති දොරවල් 3ක් තියෙනවා. එක දොරක් පිටුපස වටිනා කාර් එකක් (Car) තියෙනවා, අනෙක් දොරවල් දෙක පිටුපස ඉන්නේ එළුවෝ (Goats).

**The Rules:**

- ඔයා මුලින්ම කැමති දොරක් තෝරාගන්න ඕනේ (උදාහරණයකට දොර 1).

- දොරවල් පිටුපස තියෙන්නේ මොනවාද කියලා දන්නා Host, ඔයා තෝරා නොගත් ඉතිරි දොරවල් දෙකෙන් එළුවෙක් ඉන්න දොරක් විවෘත කරලා පෙන්වනවා (උදාහරණයකට දොර 3).

- දැන් ඔයාට අවස්ථාවක් දෙනවා ඔයා මුලින් තෝරාගත් දොරේ (දොර 1) රැඳී සිටිනවාද, නැත්නම් ඉතිරි වී ඇති අනෙක් දොරට (දොර 2) මාරු වෙනවාද (**Switch**) කියලා තීරණය කරන්න.

**The Challenge:** ඔයා දිනන්න තියෙන අවස්ථාව (**Winning Chance**) වැඩි කරගන්න නම්, දොර මාරු කරන එක (**Switch**) ද වඩාත් හොඳ, නැත්නම් මුල් දොරේම ඉන්න එකද?

---

### 💡 The Solution: Conditional Probability Logic

බොහෝ දෙනෙක් හිතන්නේ දොරවල් දෙකක් ඉතිරි නිසා දිනන්න තියෙන අවස්ථාව 50/50 කියලා. ඒත් නිවැරදි logic එකට අනුව ඔයා **Switch කළොත් දිනන්න තියෙන අවස්ථාව 2/3ක්** දක්වා වැඩි වෙනවා.

#### **The Step-by-Step Logic:**

1. **Initial Choice:** ඔයා මුලින්ම දොරක් තෝරන කොට, කාර් එක ඒ දොර පිටුපස තියෙන්න තියෙන **Probability** එක 1/3 යි. ඉතිරි දොරවල් දෙකේ කාර් එක තියෙන්න තියෙන සම්භාවිතාව 2/3 යි.

2. **Host’s Action:** Host කරන්නේ අර 2/3 ක සම්භාවිතාව තියෙන කොටසෙන් එළුවෙක් ඉන්න දොරක් ඉවත් කරලා පෙන්වන එකයි. ඔහු කවදාවත් කාර් එක තියෙන දොර අරින්නේ නැහැ.

3. **The Switch:** දැන් අර මුලින් තිබුණු 2/3 ක සම්භාවිතාවම ඉතිරි වෙලා තියෙන්නේ Host විවෘත නොකළ අනෙක් දොරටයි. එබැවින් මාරු වීමෙන් ඔයාගේ දිනීමේ අවස්ථාව දෙගුණ වෙනවා.

#### **මෙතන තියෙන Logic එක මොකක්ද?**

මෙහිදී **Conditional Probability** සහ **Decision Making** පිළිබඳව උගන්වනවා. Host ගේ ක්‍රියාව අහඹු (**Random**) එකක් නොවන නිසා, ඔහු දොරක් විවෘත කිරීම හරහා අපිට අලුත් තොරතුරක් (**New Information**) ලබා දෙනවා.

#### **මෙමගින් Programming වලට වෙන බලපෑම:**

- **Dynamic Logic:** ඔයාගේ **Code** එකක දත්ත වෙනස් වන විට (Dynamic data) logic එක වෙනස් කරගන්නා ආකාරය කියලා දෙනවා.

- **Simulation:** මෙය C++ වැනි භාෂාවකින් **Loop** එකක් ඇතුලේ දහස් වාරයක් Run කරලා බැලුවොත් (Simulation), ඇත්තටම Switch කරන එක 66.6% වතාවක් දිනන බව ඔප්පු කරන්න පුළුවන්.

# JavaScript Curriculum

JavaScript is the language of the web. It runs in every browser, powers Node.js on the server, and is the foundation of React, TypeScript, and every framework you'll use in this stack. This curriculum covers JavaScript from its core mechanics to the patterns and APIs used in production systems.

---

## Prerequisites

None. This is the starting point for the web development track.

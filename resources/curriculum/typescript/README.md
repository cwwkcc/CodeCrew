# TypeScript Curriculum

A structured, progressive curriculum for learning TypeScript from type annotations through advanced type manipulation and real-world production patterns. All 5 modules are numbered `00–04` plus a capstone — read them in order.

## Notes

- Solid JavaScript knowledge (especially ES6+) is required before starting this curriculum.
- Module 04 (Utility Types) is the most abstract — take your time with `infer` and conditional types.
- Module 05 assumes you have a Node.js project set up with a `package.json`.

# 🌬️ Tailwind CSS Curriculum

Utility‑first CSS framework: layout, flexbox/grid, typography, responsive design, configuration. 7 modules.

> **Location:** `resources/curriculum/tailwind-css/`
>
> **Updated for Tailwind v4** — CSS-first `@theme` configuration (the current default as of 2026) is taught throughout, with v3's `tailwind.config.js` approach kept as clearly-labeled legacy content since it's still what you'll find in most existing codebases. Module 06, Section 13 has the full migration guide and breaking-changes list.

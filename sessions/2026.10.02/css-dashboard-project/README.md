# CSS Class Project: StudyFlow Dashboard

A student dashboard: app shell, stat cards, CSS-only charts, a timetable, a study-streak heatmap, a checkable task list, a sticky-header table and a CSS-only dark mode switch. Plain HTML + CSS, no JavaScript.

- `final/`        finished dashboard, to show students on day one
- `starter/`      the HTML and an empty style.css
- `parts/`        one CSS file per stage, each opening with what to teach and a "break it" challenge
- `checkpoints/`  stage-1 ... stage-11: working code up to that stage

| Stage | Part | Module | What it adds |
|---|---|---|---|
| 1 | box-model | 02 | panels, spacing, reset |
| 2 | colors-backgrounds | 03 | palette, donut, pills |
| 3 | typography-units | 04, 05 | fonts, rem, clamp |
| 4 | display-positioning | 06 | sticky sidebar, labels |
| 5 | flexbox | 07 | top bar, bars, lists |
| 6 | grid | 08 | app shell, 12-column panels |
| 7 | responsive | 09 | sidebar becomes bottom bar |
| 8 | pseudo-classes-elements | 14 | tooltips, donut hole, stripes |
| 9 | transitions-transforms | 10, 12 | hover polish |
| 10 | animations | 11 | dashboard draws itself |
| 11 | custom-properties-dark-mode | 13 | dark theme |

JS-ready: theme toggle, live chart data, task filters, search.

Advanced pieces: grid driven by custom properties, color-mix(), :has(), @container, @property animation, styled checkbox and switch.

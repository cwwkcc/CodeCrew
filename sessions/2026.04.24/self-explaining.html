1. Text Elements

Headings

There are six heading levels. They define the outline and structure of your document — not the font size. Always use them in order. Never skip a level.

h1 — The main title of the page. Use only once per page.

h2 — A major section heading.

h3 — A sub-section inside an h2.

h4 — A sub-section inside an h3.

h5 — Rarely needed. A sub-section inside an h4.
h6 — The deepest level. Almost never used.

Paragraphs, Line Breaks, and Thematic Breaks

Every block of prose lives in a p tag. The browser adds spacing above and below automatically. Never use br tags to fake that spacing.

The br tag forces a line break inside a paragraph.

Use it only when the line break is part of the meaning — like an address or poem.

Semantic Inline Elements

strong — marks content as critically important or urgent. Rendered bold by default but its purpose is meaning, not styling.

em — marks stressed emphasis, the word you would stress when speaking. Compare: I did not say that — versus — I did not say that. The meaning shifts.

mark — highlights text relevant to the current context, like a search result match or a key term being introduced for the first time.

HTML — the abbr tag marks abbreviations. The title attribute holds the full expanded form. Hover your mouse over HTML above to see the tooltip.

6 August 1991 — the time tag wraps a date or time and makes it machine-readable via the datetime attribute. The content between the tags is for humans; the datetime value is for browsers and search engines.

<p>Hello</p> — the code tag marks a fragment of computer code. Rendered in a monospace font by default.

Ctrl + S — the kbd tag represents keyboard input. Use it when instructing a user to press a key.

E = mc2 — sup creates superscript.   H2O — sub creates subscript.

small — for side comments, legal fine print, and minor notes. Not a font-size control — a semantic signal that this content is supplementary.

Presentational Inline Elements

b — bold without semantic importance. Use only when bold styling is needed but the content is not genuinely urgent. Prefer strong when meaning is involved.

i — italic without stress emphasis. Use for technical terms, foreign words, or titles of works. Prefer em when meaning is involved.

u — underline without semantic meaning. Use carefully — users associate underlines with links.

Quotations

Tim Berners-Lee once said: The web is more a social creation than a technical one. — the q tag adds quotation marks automatically. Use it for short inline quotes.

The blockquote element is for long quotations that stand apart from the main paragraph flow. Use it when the quote deserves its own block, not when it sits inside a sentence.

2. Links

The a tag (anchor) creates a hyperlink. The href attribute is what makes it navigate somewhere. Without href, it is just an inert placeholder.

Types of href Values

Absolute URL — full address including the scheme:

https://www.google.com

Root-relative URL — path from the root of the site, starts with a forward slash:

Relative URL — path relative to the current file's location:

Fragment identifier — links to an element on the same page using its id attribute:

target and rel

Use target="_blank" to open a link in a new tab. Always pair it with rel="noopener noreferrer" for security and privacy. Without it, the opened page can access the parent window via JavaScript:

Navigation with nav

Wrap site navigation links in a nav element. It is a landmark element — screen readers announce it as a navigation region. Use aria-label when there are multiple nav elements on the page to tell them apart. Navigation items are always a list — nav wraps a ul with li and a inside:

3. Lists

Unordered List — ul

Use when order does not matter. Each item is an li element.

  • HTML — defines structure and meaning
  • CSS — defines visual appearance
  • JavaScript — defines behaviour and interactivity

Ordered List — ol

Use when order matters — steps, rankings, sequences.

  1. Browser sends an HTTP request to the server
  2. Server responds with an HTML document
  3. Browser parses the HTML and builds the DOM
  4. Browser renders the page on screen

ol Attributes

start — begin numbering from a custom number:

  1. This item is numbered 5
  2. This item is numbered 6
  3. This item is numbered 7

reversed — count downward:

  1. Third place
  2. Second place
  3. First place

type="a" — use lowercase letters:

  1. Option a
  2. Option b
  3. Option c

type="i" — use Roman numerals:

  1. Roman numeral i
  2. Roman numeral ii
  3. Roman numeral iii

value on li — override a specific item's number:

  1. Item one
  2. This item jumps to number 10
  3. This item continues as 11

Nested List

A nested list must go inside the parent li, not after it.

Description List — dl

Use for term-definition pairs — glossaries, metadata, key-value displays. dt is the term. dd is the definition. One dt can have multiple dd values. Multiple dt elements can share one dd.

Document Object Model — the in-memory tree the browser builds from parsed HTML.
HTTP
HyperText Transfer Protocol
The application-layer protocol used to transfer web documents. Both terms above share this single definition.

4. Tables

Tables are for tabular data — information that has a meaningful row and column relationship. Never use tables for page layout.

Full Table Structure

A complete table uses caption for the title, thead for column headers, tbody for data rows, and tfoot for summary or total rows. The scope attribute on th tells screen readers which cells the header covers.

colspan and rowspan

colspan stretches a cell across multiple columns. rowspan stretches a cell down multiple rows. When a cell uses rowspan, the rows it covers must not include that cell.

colgroup and col

colgroup lets you apply attributes to entire columns without repeating them on every cell. col is a void element — one col per column.
